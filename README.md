# PrésenceManager

## Description
PrésenceManager est une application Android de gestion des présences.

## Fonctionnalités TP03

### Gestion des événements
- **Clic simple :** ouvrir les différentes pages depuis le tableau de bord.
- **Appui long :** afficher un message d'aide pour les cartes Groupes et Faire l'appel.
- **Double-clic :** afficher une boîte de dialogue « À propos de PrésenceManager » en cliquant deux fois sur l'image du profil.

### Pages accessibles
- Groupes
- Faire l'appel
- Historique
- Statistiques
